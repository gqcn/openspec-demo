# 开发机管理模块

## 背景

AI 模型训练平台需要为算法工程师提供基于 Web 的交互式开发环境。工程师需要在云端进行模型代码开发、调试、数据探索等工作，要求环境具备持久化、弹性算力分配、多人协作等能力。

## 目标

在 Kubernetes 集群上，为平台用户提供按需创建和管理 JupyterLab 开发机实例的能力，支持环境持久化、资源规格选择、协作共享和自动回收。

## 用户

内部平台用户，规模约几十人。

## 功能范围

### 开发环境管理

| 功能 | 说明 |
|------|------|
| JupyterLab 实例 | 提供基于 Web 的交互式 IDE，每个用户最多拥有 1 个实例 |
| 环境持久化 | 用户工作目录挂载到 NFS PVC，Pod 重启后数据不丢失 |
| 资源规格选择 | 创建时从固定套餐中选择 CPU/内存/GPU 规格 |
| 镜像选择 | 创建时从后端预配置的镜像列表中选择，后续对接镜像管理模块 |
| 多实例管理 | 本期：1 用户 1 实例；支持启动、停止、重建 |
| 协作共享 | 每个实例有固定访问链接，分享链接即可协作访问 |
| 自动回收 | 实例持续闲置 48 小时后自动回收（保留数据），仅记录系统日志 |

### 开发辅助能力

| 功能 | 说明 |
|------|------|
| Web Terminal | JupyterLab 内置 Terminal，通过 WebSocket 提供 |
| Git 版本管理 | JupyterLab 内置 Git 扩展 |
| 数据集挂载 | 共享目录 `/share` 挂载于 PVC，所有用户可读写 |
| 开发调试 | JupyterLab 内置 debugger |
| 依赖管理 | pip/conda，在容器内自由安装（持久化到工作目录的 conda env） |

### 规格套餐管理

平台管理员可以增删改查规格套餐（CPU/内存/GPU 配置），用户创建实例时从套餐列表选择。

### 镜像选择

用户创建开发机时可从预设镜像列表中选择，镜像列表由后端配置文件维护，本期不提供镜像管理 UI。

## 非目标（本期不做）

- 镜像管理 UI（增删改查），镜像由配置文件维护
- 用户自定义镜像构建
- 实例回收前的用户通知
- 多用户实时协同编辑（CoLab 模式）
- LDAP/SSO 登录（预留扩展点，本期账号密码）
- 训练任务管理（独立模块）

## 技术约束

- 前端：Vue 技术栈
- 后端：GoFrame v2
- 容器编排：Kubernetes
- 数据库：MySQL 8+
- 存储：NFS（支持 RWX）
